02 — Featured project

security-headers-checker

Source code →

A Python command-line tool that checks a URL for HTTP security headers and reports which ones are missing, which look misconfigured, and which reveal information about the server.

What it does

  • Checks six recommended security headers
  • Validates values such as the HSTS max-age
  • Flags headers that leak server details
  • Table or JSON output, CI-friendly exit codes

What I learned

  • Server input can't be trusted: a malformed value crashed an early version, now covered by a test
  • Why every network request needs a timeout
  • Separating concerns with a custom exception
  • Python
  • requests
  • argparse
  • pytest
